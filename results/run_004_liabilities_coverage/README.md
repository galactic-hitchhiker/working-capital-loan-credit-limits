# Liabilities coverage investigation

Feature coverage rebuild based on run 004. It examines liabilities-related missingness and compares a rebuilt panel with the original.

The comparison files at this directory level summarize the feature coverage experiment.

No model was trained for this investigation. See `comparison.json`, `liabilities_review.json`, and `liabilities_review_queue.csv`.

`inventory/` and `panel/` (including `panel_without_statements/` where present) are local generated data and are excluded from Git. Stored manifests and workflow summaries retain the original run paths as historical provenance; after the folder rename, those paths may no longer resolve.
